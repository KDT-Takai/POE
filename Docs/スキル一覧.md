# スキル一覧

Gキー(SkillGemSystem)で装備できるスキルジェム17種+サポートジェム8種の一覧。
値の出典は `External/ECS/Systems/Skill/SkillGemData.h` / `SupportGemData.h`
（実装が正、このファイルは人間が一覧で見るための補助資料）。

Gキー画面のピッカー(スロットを選んで下に出るバッグ内ジェム一覧)には、各ジェムの
簡単な説明文がカードの3行目に表示される(`SkillGemSystem::DrawPickerCard`)。
説明文は実装側(`SkillGemData.h`/`SupportGemData.h`)も日本語で統一済み。

装備済みのスキル/Spiritスロットの行や、装着済みサポートジェムのソケットに
カーソルを乗せると、その場で小さなツールチップ(名前+簡易ステータス+説明文)が
表示される(`SkillGemSystem::DrawHoverTooltip`)。パネル右上の「スキル一覧」ボタンを
押すと、所持の有無に関わらず全ジェムをスクロール一覧できる画面に切り替わる。

## レベルスケーリング共通ルール

ジェムはレベル1〜20を持つ(サポートジェムは常にレベル1固定)。
`SkillGemScaling.h`より:

| 項目 | レベルNでの倍率/値 |
|---|---|
| ダメージ | base × (1 + (N-1)×0.06) |
| MP消費 | base × (1 + (N-1)×0.05) |
| Spirit消費 (Aura/Minion) | base × (1 + (N-1)×0.05) |
| ミニオンHP (Minion) | base × (1 + (N-1)×0.08) |
| 装備要件(STR/DEX/INT) | base(全ジェム共通8) + (N-1)×2 |

クールダウンはレベルで変化しない。19-20レベルのジェムはドロップ抽選で意図的に低確率(3乗補正)。

## サポートジェム(スキルジェムの2〜5ソケットに装着、効果は乗算のみ)

装着可否はホストスキルの`SkillTag`(挙動/属性から自動算出)で決まり、
同一スキル内で同じ`SupportCategory`のサポートは2つ同時装着できない。

| id | 名前 | 要求属性 | 必要Tag | Category | 効果 | 説明 |
|---|---|---|---|---|---|---|
| 0 | Added Damage Support | STR 20 | なし | DamageMult | dmg ×1.25 | ダメージを上げる |
| 1 | Brutality Support | STR 25 | Physical | DamageMult | dmg ×1.35 | ダメージを上げるが、物理ダメージのスキルにしか付けられない |
| 2 | Faster Attacks Support | DEX 20 | Attack | Speed | CD ×0.80 | クールダウンを短縮するが、Attack系スキルにしか付けられない |
| 3 | Efficiency Support | DEX 20 | なし | Utility | MP ×0.75 | MP消費を下げる |
| 4 | Increased Area Support | INT 20 | AreaEffect | AreaMod | range ×1.30 | 範囲を広げるが、範囲攻撃スキルにしか付けられない |
| 5 | Increased Duration Support | INT 20 | Duration | Duration | duration ×1.40 | 持続時間を延ばすが、持続時間を持つスキルにしか付けられない |
| 6 | Concentrated Effect Support | INT 25 | AreaEffect | AreaMod | dmg ×1.40, range ×0.70 | ダメージを上げる代わりに範囲を狭める(範囲攻撃スキル専用) |
| 7 | Elemental Focus Support | INT 25 | Elemental | DamageMult | dmg ×1.30 | ダメージを上げるが、元素(非物理)ダメージのスキルにしか付けられない |
